### Sistema de 5 fases de marcadores
El botón **MARCADORS** ahora tiene 5 fases progresivas. Cada clic avanza una fase (F1→F2→F3→F4→F5→F1...). El letrero muestra `F1/5 Marcadores Raw`, `F2/5 SNAP`, etc.

| Fase | Qué hace | Dónde |
|------|----------|-------|
| **F1/5 Marcadores Raw** | Faros a `idealPosSec` exacto, **sin snap** + OnAirDeducido + àncora `block.in` | [`flow_assembly.js:3243-3400`](js/workflows/flow_assembly.js:3243) |
| **F2/5 SNAP** | F1 + `snapToCutFaro()` (±10s + REGLA CERO) | [`flow_assembly.js:1786`](js/workflows/flow_assembly.js:1786) |
| **F3/5 COINC** | F2 + D3-COINC + FARO-START/END | [`flow_assembly.js:2579`](js/workflows/flow_assembly.js:2579) |
| **F4/5 APROX** | F3 + greedySnapshot bidireccional | [`flow_assembly.js:2633`](js/workflows/flow_assembly.js:2633) |
| **F5/5 COMPLET** | F4 + gráficos + validación | (sin guardia, ejecución completa) |
