La Arquitectura de la Solución (CEP)
En este modelo, tu extensión tiene dos capas:
1. Panel (JavaScript/HTML): La interfaz donde el usuario hace clic.
2. Motor (ExtendScript .jsx): Un archivo separado que contiene la lógica real de Premiere.
Tu panel envía órdenes al motor así:
// Desde tu archivo .js del panel
var csInterface = new CSInterface();
csInterface.evalScript('cambiarInterpolacion()');
Ejemplo de Manejo de Interpolación con ExtendScript
Este es el script .jsx que iría en tu carpeta de extensión. 
Este código busca el primer clip, añade keyframes y cambia su tipo de interpolación 
(de Lineal a Curva o Mantenido).
/* 
   ARCHIVO: HostScript.jsx
   Este código se ejecuta dentro del contexto de Premiere Pro
*/

function cambiarInterpolacion() {
    var project = app.project;
    if (!project.activeSequence) return;

    var sequence = project.activeSequence;
    var track = sequence.videoTracks; // Primera pista de video
    
    if (track.clips.numItems === 0) return;
    var clip = track.clips; // Primer clip

    // 1. Acceder al efecto "Movimiento" (Motion) y propiedad "Posición"
    // Nota: Los índices pueden variar según versión, pero Motion suele ser el último o el fijo.
    // Una búsqueda robusta busca por nombre, pero aquí usamos índices comunes.
    var components = clip.components;
    var motionComponent;
    
    for (var i = 0; i < components.numItems; i++) {
        if (components[i].displayName === "Motion" || components[i].displayName === "Movimiento") {
            motionComponent = components[i];
            break;
        }
    }

    if (!motionComponent) return;

    var positionParam = motionComponent.properties; // Posición suele ser el 0
    
    // 2. Habilitar variación de tiempo
    if (!positionParam.isTimeVarying()) {
        positionParam.setTimeVarying(true);
    }

    // 3. Definir tiempos (segundos)
    var t1 = clip.inPoint.seconds + 0.5;
    var t2 = clip.inPoint.seconds + 2.0;

    // 4. Crear Keyframes
    positionParam.addKey(t1);
    positionParam.addKey(t2);

    // 5. Asignar valores (En ExtendScript clásico, la posición es un Array [x, y])
    // Nota: 0.5, 0.5 es el centro de la pantalla
    positionParam.setValueAtKey(t1, [0.5, 0.5], true); 
    positionParam.setValueAtKey(t2, [0.8, 0.5], true);

    // --- AQUÍ ESTÁ LA MAGIA DE LA INTERPOLACIÓN ---

    // Primero, necesitamos encontrar el ÍNDICE del keyframe basado en su tiempo.
    // addKey no siempre devuelve el índice, así que lo buscamos.
    var keyIndex1 = encontrarKeyframePorTiempo(positionParam, t1);
    var keyIndex2 = encontrarKeyframePorTiempo(positionParam, t2);

    if (keyIndex1 !== -1) {
        // Cambiar el primer keyframe a BEZIER (Curva suave)
        // 0 = Linear, 1 = Bezier, 4 = Hold (Mantenido)
        positionParam.setInterpolationTypeAtKey(keyIndex1, 1, true); 
    }

    if (keyIndex2 !== -1) {
        // Cambiar el segundo keyframe a HOLD (Salto brusco)
        positionParam.setInterpolationTypeAtKey(keyIndex2, 4, true); 
    }
}

El Problema de "Encontrar el Keyframe"
Como notarás en el código, el gran desafío de CEP/ExtendScript es que no existe un método nativo fácil 
para decir "dame el índice del keyframe en el segundo 5".
Por eso, la comunidad de desarrolladores utiliza esta estrategia:
1. Limpiar todos los keyframes existentes antes de empezar (para asegurar que el índice 0 es tu primer keyframe).
2. Llevar un contador manual de cuántos keyframes has insertado.
3. Asumir que si insertaste el primero en t1, su índice es 0.
Referencia de Tipos de Interpolación (Cheat Sheet)
Usa estos números en la función setInterpolationTypeAtKey(index, type):
Valor
Nombre
Comportamiento
0
Linear
Velocidad constante. Movimiento robótico.
1
Bezier
Permite curvas. Suaviza la entrada/salida manualmente.
2
Continuous Bezier
Suavizado automático que mantiene la continuidad.
3
Auto Bezier
Premiere calcula la curva óptima.
4
Hold (Mantenido)
El valor se congela hasta el siguiente keyframe (corte directo).
Resumen
Si necesitas control total hoy para un trabajo profesional en Premiere 25.0+, 
tu mejor ruta es crear un Panel Híbrido:
• Usa UXP para la interfaz bonita si quieres estar al día.
• Pero mantén un archivo .jsx (ExtendScript) en tu proyecto y llámalo para las 
tareas pesadas de keyframes, ya que UXP todavía arroja errores como el "Illegal 
Parameter Type" y carece de documentación sobre interpolación.
