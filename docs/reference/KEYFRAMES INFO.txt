Guía de Manipulación de Propiedades (Premiere 2025+)
Para replicar este éxito en otras propiedades (como Scale o Rotation), sigue siempre este orden quirúrgico para evitar que el reloj se quede en gris o los valores se reseteen:

Captura Preventiva: Lee el valor actual con .getValueAtTime(currentTime) antes de activar nada.

Despertar del Motor: Usa .setTimeVarying(true) seguido inmediatamente de un .setValue(valor, true). Esto obliga al icono del cronómetro a ponerse azul.

Inserción de Key: Usa .addKey(currentTime).

Inyección por Índice: No confíes en setValueAtTime. Busca el índice del keyframe recién creado con un bucle for y usa .setValueAtKey(index, valor, true).

Refresco de UI: Forzar la deselección y selección del clip (setSelected) es obligatorio para que el usuario vea el diamante al instante.

/*
    ESTÁNDAR DE INSERCIÓN PARA PREMIERE 2025+
    Propósito: Activar cronómetro, insertar keyframe y refrescar UI.
    Nota: Se usa setValueAtKey para evitar ReferenceError en NewWorld.
*/
function baseInsertKeyframe(propertyIndex) {
    try {
        var seq = app.project.activeSequence;
        var sel = seq.getSelection();
        var clip = (sel && sel.length > 0) ? sel[0] : seq.videoTracks[0].clips[1];
        
        if (!clip) return "Error: No hay clip";

        // 1. Acceso a la propiedad (0: Position, 1: Scale, 2: Anchor Point, etc.)
        var prop = clip.components[1].properties[propertyIndex];
        var currentTime = seq.getPlayerPosition();
        
        // 2. CAPTURA: Guardar valor actual antes de animar
        var val = prop.getValueAtTime(currentTime);

        // 3. DESPERTAR MOTOR: Forzar cronómetro azul
        prop.setTimeVarying(true);
        prop.setValue(val, true); // Escribir valor estático activa el motor

        // 4. INSERCIÓN: Crear el diamante en el tiempo del Timeline
        prop.addKey(currentTime);

        // 5. SINCRONIZACIÓN: Buscar índice para evitar el reset a 0,0
        var keys = prop.getKeys();
        for (var k = 0; k < keys.length; k++) {
            if (Math.abs(keys[k].seconds - currentTime.seconds) < 0.005) {
                // Inyectamos el valor capturado en el índice encontrado
                prop.setValueAtKey(k, val, true);
                break;
            }
        }

        // 6. REFRESCO NUCELAR: Obligatorio para ver cambios en Control de Efectos
        clip.setSelected(false, false);
        clip.setSelected(true, true);

        return "✅ Keyframe base insertado correctamente";
    } catch (e) {
        return "Error en Base: " + e.toString();
    }
}

1. Captura,getValueAtTime(),"Evita que al crear el keyframe los valores salten a 0,0 o valores por defecto."
2. Activación,setTimeVarying(true) + setValue(),"Sin el setValue posterior, el icono del reloj a menudo se queda gris aunque haya keys."
3. Tiempo,seq.getPlayerPosition(),Hemos confirmado que Premiere 25.0 usa tiempo absoluto del Timeline para Motion.
4. Escritura,"setValueAtKey(index, val)",El método setValueAtTime lanza ReferenceError en el nuevo motor NewWorld.
5. Feedback,setSelected(false/true),"Sin esto, el diamante no aparece visualmente en el panel hasta que mueves el ratón."
